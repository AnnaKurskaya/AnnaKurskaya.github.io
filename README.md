# Homescapes Expert

Учебная экспертная система выбора стратегии для Homescapes. Работа Курской Анны, группа **СГН3-73Б**. Сделана в отдельной папке на основе архитектуры ДЗ Гусева.

Сайт: **https://annakurskaya.github.io/**. Репозиторий: [AnnaKurskaya.github.io](https://github.com/AnnaKurskaya/AnnaKurskaya.github.io).

## Запуск

Нужен Node.js 20 или новее. Из папки проекта выполните:

```powershell
npm start
```

Откройте **http://127.0.0.1:8080**. Установка пакетов не нужна. Через двойной щелчок по `index.html` браузер не сможет загрузить JSON: нужен HTTP-сервер. Для публикации подойдёт любой статический хостинг, включая GitHub Pages; сборка не требуется.

Проверки:

```powershell
npm test
```

28 тестов проверяют данные, цепочки вывода, возврат, формулы оценок и представления. Перебор 10 816 вариантов ветвления по всем условиям правил вывода подтверждает 21–28 ответов в полной консультации. Другие ответы влияют на баллы, но не на пропуски.

## Что умеет система

- Задаёт вопросы о целях уровня, ситуации и предпочтениях игрока.
- После каждого ответа пересчитывает и показывает пять лучших стратегий.
- Выводит новые факты по правилам и пропускает уже выясненные вопросы.
- В конце показывает все 20 стратегий с баллами и объяснением вкладов правил.
- Даёт посмотреть всю базу знаний, рабочие факты, журнал вывода и исходные JSON.
- Позволяет вернуться назад, начать заново, закончить досрочно и продолжить консультацию.
- Скачивает снимок сеанса в JSON. Сеанс хранится в памяти вкладки, перезагрузка его очищает.

В базе 20 стратегий, 12 числовых свойств, 5 дополнительных признаков, 28 вопросов и параметров, 84 правила оценки и 10 правил вывода новых фактов. Досрочное завершение может содержать меньше 20 ответов; количественная гарантия относится к полной консультации.

## Файлы

| Файл | Назначение |
|---|---|
| `data/entities.json` | Стратегии, их свойства и критерий разрешения равных оценок |
| `data/questions.json` | Тексты вопросов, варианты ответов, параметры и иллюстрации |
| `data/rules.json` | Все связи ответов со свойствами и все правила вывода |
| `js/knowledgeBase.js` | Проверка структуры и связей базы знаний |
| `js/inferenceEngine.js` | Прямой вывод, выбор следующего вопроса, воспроизведение истории |
| `js/ranking.js` | Универсальный расчёт баллов по правилам |
| `js/entityViews.js`, `js/inspectionViews.js` | Рейтинг, объяснения, просмотр баз |
| `js/app.js` | Кнопки, вкладки и обновление страницы |
| `img/` | Оригинальные условные схемы игрового поля |
| `.docs/73 ЭС ДЗ Курская А.docx` | Отчёт с данными, алгоритмом и примерами |
| `.docs/HOW_IT_WORKS.md` | Простое объяснение устройства и сценарий защиты |
| `.docs/REQUIREMENTS.md` | Проверка требований задания и связи с лекциями |

## Основа и источники

Механизм вывода адаптирован из [ДЗ Гусева](https://github.com/GusevCode/GusevCode.github.io). Предметная база, оригинальные схемы, светлый интерфейс с зелёной навигацией, сценарии, проверки и отчёт подготовлены для Homescapes. Для публикации используется репозиторий Курской с сохранённой историей его коммитов.

Механики усилителей сверены с официальной справкой Playrix: [усилители](https://playrix.helpshift.com/hc/en/14-homescapes/faq/16313-power-ups-and-how-to-use-them/), [комбинации](https://playrix.helpshift.com/hc/en/14-homescapes/faq/16363-what-power-up-combinations-are-available-in-the-game/), [советы](https://playrix.helpshift.com/hc/en/14-homescapes/faq/5905-how-to-beat-a-difficult-level/). Оценки 1–5, веса и предположения правил — условная авторская модель, а не официальные показатели игры и не вероятность победы. Система выбирает общую тактику по описанию игрока; конкретные ходы и доступность комбинаций проверяет сам игрок. Иллюстрации нарисованы для проекта и не содержат скриншотов или логотипов игры.
