# AnnaKurskaya.github.io

Учебная экспертная система выбора стратегии Homescapes по ОИС, ДЗ 2-1.

20 вопросов, 12 параметров профиля, 8 фактов уровня, 20 стратегий, 11 свойств и 12 продукционных правил. После каждого ответа показывается топ-5 по известным данным; после подтверждения — полный рейтинг и объяснения. Изменение ответа пересчитывает оценку, перезапуск очищает сессию.

```sh
npm install
npm run dev
```

Проверка: `npm test` (20 тестов) и `npm run build`. База знаний и рабочая база доступны в инспекторах приложения.

Базовая оценка — среднее совпадений известных факторов с их весами (0–100). К ней добавляются бонусы и штрафы активных правил. Общие границы `L` и `U` складываются из минимума и максимума эффектов каждого активного правила по всем стратегиям, с исходными границами 0 и 100. Итог: `100 × (baseScore + ruleAdjustment − L) / (U − L)`. Общий диапазон сохраняет различия исходных оценок без обрезания до 100. Неизвестные параметры не участвуют в средней оценке и условиях правил.
