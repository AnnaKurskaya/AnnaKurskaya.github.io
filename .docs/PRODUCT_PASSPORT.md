# Паспорт проекта экспертной системы

## Название проекта

**Разработка экспертной системы выбора оптимальной стратегии прохождения
уровней в игре Homescapes**

## Учебная дисциплина

Основы интеллектуальных систем

## Тип работы

Домашнее задание 2-1 (4 курс, 7 семестр)

## Среда разработки

Язык программирования: **JavaScript**

Планируемая реализация: - клиентская часть для взаимодействия с
пользователем; - модуль базы знаний; - рабочая база данных параметров
пользователя; - механизм логического вывода; - модуль ранжирования
объектов предметной области.

------------------------------------------------------------------------

# Условие задания

Необходимо разработать прототип экспертной системы в выбранной
предметной области.

Предметная область должна соответствовать требованиям: - не нарушать
законодательство Российской Федерации; - соответствовать общепринятым
моральным принципам.

Прототип экспертной системы должен обладать следующими возможностями:

1.  При использовании собственной разработки система должна иметь
    автономную базу знаний и рабочую базу данных с возможностью
    просмотра их содержимого.
2.  Система должна получать информацию от пользователя о его
    предпочтениях, возможностях и особенностях поведения в выбранной
    предметной области.
3.  На основе полученных данных, базы знаний и механизма логического
    вывода система должна отображать ранжированные объекты предметной
    области в порядке предпочтительности.
4.  Процесс получения информации, анализа и отображения результатов
    должен происходить в интерактивном режиме.
5.  В конце работы системы должны выводиться все объекты с указанием их
    итогового ранга.

## Требования к прототипу

-   количество вопросов пользователю: не менее 20;
-   количество параметров пользователя: не менее 10;
-   количество объектов ранжирования: не менее 20;
-   количество свойств объектов: не менее 10.

------------------------------------------------------------------------

# Концепция экспертной системы

## Предметная область

Homescapes --- мобильная игра в жанре «три в ряд», где игрок проходит
уровни, выполняя различные игровые задачи за ограниченное количество
ходов.

Каждый уровень отличается: - целями прохождения; - количеством и типом
препятствий; - расположением игровых элементов; - доступными
усилителями; - сложностью выполнения задачи.

Игроку необходимо принимать решения о том, какие действия выполнять в
первую очередь, какие усилители использовать и как рационально
распределять ограниченное количество ходов.

------------------------------------------------------------------------

# Назначение системы

Разрабатываемая экспертная система предназначена для выбора наиболее
подходящей стратегии прохождения уровня Homescapes.

Система получает информацию о текущей ситуации игрока и на основе
заложенных знаний формирует список наиболее подходящих стратегий,
расположенных в порядке предпочтительности.

Главная задача системы --- формализовать опыт игроков и представить его
в виде рекомендаций, которые помогут выбрать эффективный вариант
прохождения.

------------------------------------------------------------------------

# Принцип работы системы

Пользователь отвечает на вопросы, связанные с:

-   текущим уровнем игры;
-   сложностью ситуации;
-   количеством оставшихся ходов;
-   наличием препятствий;
-   доступными усилителями;
-   стилем игры;
-   отношением к использованию ресурсов.

После анализа ответов система выполняет сопоставление полученных
параметров с характеристиками возможных стратегий.

В результате пользователь получает: - список подходящих стратегий; - их
рейтинг; - объяснение выбора наиболее подходящих вариантов.

------------------------------------------------------------------------

# Объекты ранжирования

В качестве объектов экспертной системы используются стратегии
прохождения уровней Homescapes.

Примеры объектов:

1.  Использование самолётиков для удаления удалённых целей.
2.  Использование бомб для разрушения групп препятствий.
3.  Использование ракет для очистки линий.
4.  Комбинация «бомба + ракета».
5.  Комбинация «бомба + самолётик».
6.  Использование радужного шара.
7.  Создание усилителей в начале уровня.
8.  Сначала очистить препятствия, затем выполнять цели.
9.  Сначала выполнять основные цели уровня.
10. Экономное использование усилителей.
11. Использование всех доступных ресурсов сразу.
12. Тактика быстрого прохождения.
13. Тактика осторожного прохождения.
14. Очистка центральной части поля.
15. Очистка краёв игрового поля.
16. Освобождение закрытых областей.
17. Создание длинных комбинаций.
18. Использование дополнительных ходов.
19. Повторное прохождение с другой стратегией.
20. Комбинированная стратегия.

------------------------------------------------------------------------

# Параметры пользователя

Система учитывает следующие характеристики пользователя:

-   опыт игры;
-   предпочитаемый стиль прохождения;
-   количество доступных усилителей;
-   количество игровых ресурсов;
-   готовность использовать бустеры;
-   отношение к повторному прохождению;
-   желание пройти уровень быстро;
-   терпение к сложным уровням;
-   наличие дополнительных ходов;
-   текущая сложность уровня;
-   количество оставшихся ходов;
-   тип цели уровня.

------------------------------------------------------------------------

# Атрибуты объектов

Каждая стратегия описывается набором свойств:

-   эффективность против препятствий;
-   скорость прохождения;
-   требуемый опыт игрока;
-   расход ресурсов;
-   зависимость от случайности;
-   эффективность против большого количества целей;
-   эффективность против закрытых зон;
-   сложность применения;
-   необходимость усилителей;
-   вероятность успешного прохождения;
-   универсальность стратегии.

------------------------------------------------------------------------

# База знаний

База знаний будет содержать информацию о взаимосвязи параметров
пользователя и характеристик стратегий.

Пример логики:

Если игрок имеет мало ходов и большое количество препятствий, то
стратегии с использованием массовых усилителей получают более высокий
приоритет.

Если пользователь предпочитает экономное прохождение, то стратегии с
минимальным использованием ресурсов получают дополнительные баллы.

------------------------------------------------------------------------

# Рабочая база данных

Рабочая база данных содержит параметры, полученные от пользователя во
время работы системы:

-   ответы на вопросы;
-   выбранные характеристики уровня;
-   предпочтения игрока;
-   промежуточные результаты анализа;
-   итоговые рейтинги объектов.

------------------------------------------------------------------------

# Механизм логического вывода

В системе планируется использовать механизм взвешенного ранжирования.

Каждый объект получает определённое количество баллов в зависимости от
соответствия параметрам пользователя.

После обработки всех параметров система формирует итоговый список
стратегий от наиболее подходящей к менее подходящей.

------------------------------------------------------------------------

# План разработки

## Этап 1

Проектирование предметной области: - определение объектов; - создание
атрибутов; - формирование параметров пользователя.

## Этап 2

Создание базы знаний: - описание связей между параметрами и объектами; -
формирование правил оценки.

## Этап 3

Разработка интерфейса: - создание формы вопросов; - отображение
результатов.

## Этап 4

Разработка механизма вывода: - обработка ответов; - расчёт рейтингов; -
сортировка объектов.

## Этап 5

Тестирование: - проверка работы системы; - анализ корректности
рекомендаций.

------------------------------------------------------------------------

# Итоговый результат

В результате должна быть разработана работающая экспертная система,
которая позволяет пользователю получить рекомендации по выбору стратегии
прохождения уровней игры Homescapes на основе анализа его ответов и
характеристик игровой ситуации.
