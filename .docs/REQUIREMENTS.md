# Соответствие заданию и лекционной архитектуре

Условие: [ДЗ 2-1](https://docs.google.com/document/d/1vPgJlbcabIdzKcN8qTEoXOuH7V-XgFyOPIYD3-Hoz8U/edit). Лекции: [экспертные системы](https://docs.google.com/document/d/1n_I9Q16gGxgctgIYZ42eU1rMHR_XUuPcrLCqz4kk48k/edit), [архитектура ЭС](https://docs.google.com/document/d/1V86C9Gl6rfGonnrhzZYOcuQgR-C5a1-FRQF8G5I0pA0/edit).

| Проверка | Результат и способ проверки |
|---|---|
| Не менее 20 объектов | 20 стратегий, просмотр «Объекты» |
| Не менее 10 свойств | 12 числовых свойств и 5 дополнительных признаков |
| Не менее 10 пользовательских параметров | 28 параметров в базе вопросов |
| Не менее 20 вопросов с учётом пропусков | 21–28 явных ответов в полной консультации; 10 816 ветвей пропусков в тесте |
| Топ-5 после каждого ответа | Проверено на каждом шаге двух браузерных сценариев |
| Все объекты в конце | 20 результатов с объяснениями |
| Автономная просматриваемая БЗ | Три JSON, таблицы и поиск обоих видов правил |
| Рабочая база текущего сеанса | Факты и происхождение, история, журнал, оценки и JSON-снимок |
| Связь параметров со свойствами | 84 правила `score`, все значимые ответы покрыты |
| Связь параметров между собой | 10 правил `derive`, включая двухступенчатые цепочки |
| Возврат и пересчёт | История воспроизводится заново, устаревшие факты исчезают |
| Отчёт | Титул, аннотация, разделы 1–9, полная матрица свойств, вопросы/ответы, правила, алгоритм, два графа выбора, источники |
| Формат отчёта | Группа СГН3-73Б, файл `73 ЭС ДЗ Курская А.docx`, поля 3/1,5/2/2 см, обновляемое оглавление |

В терминах лекций это продукционная рекомендательная ЭС: постоянная база знаний отделена от рабочей памяти, машина вывода строит новые факты до неподвижной точки, подсистема объяснений показывает сработавшие правила. Пользователь работает через консультацию; разработчик пополняет знания в JSON и проверяет их валидатором. Отдельный интерактивный модуль редактирования знаний не реализован.

Проверено: **28 из 28 автотестов**, два полных браузерных сценария с 21 и 26 ответами, ширина экрана 1440 и 390 px, ошибок JavaScript нет. Проверки относятся к этой версии и её базе. Числовые оценки и веса остаются авторскими эвристиками: это не результаты обучения или валидации на статистике уровней.
